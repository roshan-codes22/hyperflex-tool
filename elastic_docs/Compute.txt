Metrics
The
compute
dataset is designed to fetch metrics for
Compute Engine
Virtual Machines in Google Cloud Platform. It contains all metrics exported from the
GCP Cloud Monitoring API
.
Extra labels and metadata are also extracted using the
Compute API
. This is enough to get most of the info associated with a metric like Compute labels and metadata and metric specific Labels.
