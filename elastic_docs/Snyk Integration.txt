This integration is for ingesting data from the
Snyk
API. The integration allows collection of audit logging information and vulnerability issues via the Snyk
REST API
.
REST API
issues
: Collects all found issues for the related organizations and projects.
audit_logs
: Collects audit logging from Snyk, this can be actions like users, permissions, groups, api access and more.
To configure access to the Snyk REST Audit Log API you will have to obtain an API access token from
your Snyk account dashboard
as described in the
Snyk Documentation
.
