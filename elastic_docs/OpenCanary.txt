This integration is for
Thinkst OpenCanary
honeypot event logs. The package processes messages from OpenCanary honeypot logs.
Data streams
The OpenCanary integration collects the following event types:
events
: Collects the OpenCanary logs.
Requirements
Elastic Agent must be installed. For more details, check the Elastic Agent
installation instructions
.
Enable the integration in Elastic
In Kibana navigate to
Management
>
Integrations
.
In the search top bar, type
OpenCanary
.
Select the
OpenCanary
integration and add it.
Add all the required integration configuration parameters.
Save the integration.
